# IDX Exchange - Agentic AI Internship

Multi-week real estate AI project built with OpenClaw, Gemini, TypeScript, MySQL, and MLS data.

## Tech Stack

- TypeScript / Node.js
- MySQL
- Gemini API
- OpenClaw
- WhatsApp
- Embeddings + Cosine Similarity

Build a multi-agent real estate assistant with property search, market analytics, semantic search, memory, and OpenClaw-based orchestration.
